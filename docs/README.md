# Documentation lives in Obsidian

PRD documentation for this project — the PRD, delta specs, task files, reports, and the
acceptance/reference notes — is kept in the team Obsidian vault, **not** in this repo:

> `thothlab/openclaw_obsidian_vault` → `Projects/my-git/terminal/`
> (`PRDs/prd_01_tui-git-manager/`, `notes/`, and, after archival, `specs/`).

This follows the `/prd` skill convention: PRD docs/specs live in the project's Obsidian
folder; only if the vault is unavailable do they fall back to this `docs/` directory.

Human-facing summaries there: `Итоговый отчёт.md`, `План задач и отчёты.md`, `index.md`.
